# Bug Description

`gsm_get_time` searches the modem reply for the `+CCLK: "` prefix. The result is
used without a null check: the function adds the prefix length and passes that
pointer to `strtok`. When a malformed or incomplete reply lacks the prefix, the
null result becomes a small address and the tokenizer faults while treating it
as a string.

The function must stop parsing when the prefix search fails, before applying
the offset or calling any further string routine.
