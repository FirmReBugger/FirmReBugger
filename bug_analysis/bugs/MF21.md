# Bug Description

RIOT's CCN-Lite integration embeds a timeout event inside every face object and
links that event into a shared event timer. Face removal unlinks and frees the
face but does not remove its timeout event. A receive operation can rearm the
event after its earlier timeout message has been queued but before that message
is handled, so the queued timeout then frees a face whose rearmed event is still
live.

The event timer later follows fields in the freed face or submits the embedded
message from storage that may already have been reused by another allocation.
This is a use-after-free that can corrupt a replacement object and eventually
drive the timer or message dispatcher through invalid pointers. Face removal
must cancel the embedded event, and any already queued timeout message, before
releasing the face.
