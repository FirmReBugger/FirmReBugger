# Bug Description

The Modbus function-6 handler rejects a register address only when it is greater
than `MODBUS_SLAVE_REGISTERS_NUM`. Because the register array contains 256
elements indexed from 0 through 255, address 256 passes this test and is used as
an array index. The resulting halfword store lands immediately beyond
`modbusMemory`.

A remote Modbus request can therefore cause a controlled out-of-bounds write by
using register address 256.
