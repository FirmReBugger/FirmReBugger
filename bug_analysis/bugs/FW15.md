# Bug Description

`Modbus::process_FC3` handles function code 3, Read Holding Registers. It decodes a starting register offset and register count from the request, reads `au16data[offset + i]` for each requested register, and appends two response bytes to the buffer embedded in the `Modbus` object.

The byte cursor is incremented twice per register, but the function checks only whether it has processed the requested count. It does not validate `offset + count` against the source array or ensure that `count * 2` fits the response buffer. A large request therefore drives the cursor beyond the object-owned buffer and overwrites adjacent global state.

If callback tables or pointers follow the object, the overrun can replace one of those values and remain latent until another subsystem invokes it. Correct handling requires rejecting an excessive range before copying and ensuring that both the source range and encoded response length fit their respective arrays.
