# Bug Description

`Modbus::process_FC1` handles function code 1, Read Coil Status. It decodes the requested coil count with `makeWord()` and then runs a bit-packing loop that writes the selected coil values into the response buffer beginning inside the `Modbus` object. An eight-bit byte cursor advances as each group of coil bits is produced.

The loop is bounded only by the attacker-controlled coil count. It never compares the number of response bytes with the actual response-buffer capacity. A sufficiently large count therefore advances the cursor beyond the buffer and continues writing through fields and global objects that follow the `Modbus` instance.

The corruption is not necessarily consumed immediately. It can overwrite serial callback pointers or other control data that a later interrupt handler calls indirectly, making the visible control-flow failure remote from `process_FC1`. The count must be validated against both the protocol limit and the local response capacity before entering the loop.
