# Bug Description

The Modbus function-3 handler permits a request for 126 registers. The response
contains a function byte, a byte-count field, 252 register-data bytes, and a
two-byte CRC, for a total length of 257 bytes. `modbusRxTxBuffer` has room for
only 256 bytes, so the second CRC byte is stored one byte beyond the array and
overwrites the adjacent `modbusRxCount` state.

An unauthenticated Modbus client can select the maximum accepted register count
and cause deterministic RAM corruption. Depending on the overwritten state and
subsequent processing, the corruption can disrupt protocol handling or crash
the device. 

The firmware configures USART1 receive through DMA on the STM32F303RE, a
documented peripheral combination in the
[STM32F303RE datasheet](https://www.st.com/resource/en/datasheet/stm32f303re.pdf).
