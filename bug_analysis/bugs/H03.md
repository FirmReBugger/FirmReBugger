# Bug Description

This defect is tracked as CVE-2023-23609.

The BLE L2CAP input path reassembles fragmented service data units in a
channel buffer that is larger than Contiki's global 128-byte `packetbuf`.
When reassembly completes, the implementation copies the entire SDU into
`packetbuf` without checking whether the completed length fits the smaller
destination.

An SDU longer than 128 bytes therefore makes `memcpy` write beyond
`packetbuf`. The adjacent memory contains network-processing state, so the
overflow can corrupt list heads and other pointers that are consumed later
by the IPv6 stack, resulting in invalid memory accesses or redirected control
flow.

The oversized SDU can be assembled from multiple ordinary received frames;
it does not require a single overlength physical radio frame.
