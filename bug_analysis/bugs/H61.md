# Bug Description

This is **CVE-2023-0359**. `handle_ra_input` processes an IPv6 Router Advertisement and obtains the interface's IPv6 configuration from `net_pkt_iface(pkt)->config.ip.ipv6`. That pointer is NULL until IPv6 has been configured on the interface.

The function guards other uses of the same pointer, including reachable-time getters and base-time updates, but passes it without a NULL check to `net_if_ipv6_set_reachable_time`. That routine forwards the pointer into `net_if_ipv6_calc_reachable_time`, which dereferences IPv6 configuration fields.

A Router Advertisement arriving before interface IPv6 setup completes can therefore reach the calculation with a NULL configuration pointer. `handle_ra_input` must verify that the interface has IPv6 state before applying advertised timing values, or defer RA processing until configuration is complete.
