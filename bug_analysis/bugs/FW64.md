# Bug Description

CVE-2021-3322 is an unexpected pointer-aliasing defect in Zephyr's IEEE
802.15.4 fragment reassembly. When the first received fragment already accounts
for the complete datagram, the cache packet and input packet are the same
object. Completion code transfers the cache buffer to the input packet and then
clears the cache buffer; because the two packet pointers alias, it clears the
buffer it just assigned.

`net_6lo_uncompress()` subsequently dereferences the NULL packet buffer and
crashes. Both `zephyr-sam4s` benchmark variants (`FirmBench` and
`FirmBenchX`) contain this vulnerable ownership transfer, and the AT86RF233
radio provides the real IEEE 802.15.4 input path.
