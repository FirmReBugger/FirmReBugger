# Bug Description

The PWM cycles command accepts any object returned by the generic device registry and passes it to the inline PWM setter. The wrapper reads API slot zero as `pwm_pin_set_cycles` and calls it without verifying the object's subsystem.

For a real STM32 PWM device the slot contains `pwm_stm32_pin_set`. If the supplied name identifies another registered device, slot zero belongs to a different API and may have a different function signature or meaning. The PWM arguments are then delivered to unrelated code, allowing cross-subsystem type confusion and invalid indirect dispatch.

The command must require a PWM API table, or use a typed device lookup, before calling the setter.
