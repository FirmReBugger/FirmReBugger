# Bug Description

The 6LoWPAN selective-fragment-recovery sender initializes `_arq_timer` only
after successfully preparing a fragment that requests an acknowledgement. An
earlier processing or allocation failure can take an error path that schedules
the same timer without performing that initialization.

When the scheduled event fires, the event timer uses the uninitialized
callback pointer and faults. An attacker can pressure the packet buffer with
fragments and then provoke the failing send, resulting in denial of service.
This defect is
[CVE-2023-24826](https://github.com/RIOT-OS/RIOT/security/advisories/GHSA-xfj4-9g7w-f4gh).
