# Bug Description

The clock-query routines recursively resolve a generic clock generator to its selected source and, where appropriate, resolve that source through another generator. The implementation assumes that the source graph is acyclic because valid hardware configurations ultimately terminate at an oscillator or fixed clock.

Reserved source and generator encodings can instead make one generator resolve back to itself or create a cycle between generators. The recursive query then has no terminating case. Repeated frames exhaust the stack and eventually overwrite adjacent BSS state, causing failures in unrelated clock or peripheral code.

# False Positive Reason

The cycle requires reserved ATSAMR21G18A GCLK encodings that are excluded from valid clock-controller state. Firmware does not program those combinations, and the physical peripheral does not spontaneously produce them. The recursive cycle therefore depends on independently synthesized register values outside the device's documented domain.
