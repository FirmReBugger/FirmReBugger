# Bug Description

The MIDI parser constructs ordinary channel messages in storage embedded in the
global `midiMsgBuilder`. When it dispatches a note-off message, the callback
unconditionally passes that embedded object to `free()`, even though the object
was never returned by the heap allocator.

A MIDI note-off command received through the USART2 DMA input path can therefore
corrupt allocator state or crash the firmware, causing denial of service.
