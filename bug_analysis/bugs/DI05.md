# Bug Description

The MIDI parser uses a message object embedded in the global `midiMsgBuilder`
for normal channel messages. The note-on callback nevertheless calls `free()`
on that static object's address. Since the pointer does not identify a heap
allocation, the deallocation violates the allocator's ownership contract.

A MIDI note-on command delivered through USART2 DMA can invoke the invalid free,
leading to allocator corruption or an immediate crash and denial of service.
