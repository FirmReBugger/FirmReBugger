# Bug Description

CVE-2021-3321 affects Zephyr's 6LoWPAN fragment reconstruction. The receiver
accepts a fragment without first proving that its buffer contains the complete
fragmentation header. Header removal chooses four bytes for FRAG1 and five for
FRAGN, then computes `frag->len - hdr_len` using an unsigned length.

When the fragment is shorter than its selected header, the subtraction wraps
to a value near `UINT_MAX`. That value becomes the length of a `memmove` within
the network buffer, producing a large out-of-bounds write that can corrupt
kernel data and control state. The vulnerable instructions and object layout
are present in the firmware, and attacker-controlled IEEE 802.15.4 fragments
drive this exact source-level path.
