# Bug Description

CVE-2021-3330 is a list-maintenance defect in Zephyr's IEEE 802.15.4 fragment
reassembly. When a later fragment must move before the current head and there is
no predecessor, `fragment_move_back` links the fragment to the old head but does
not update `pkt->buffer`. A forged sequence containing only subsequent-fragment
headers can therefore turn the reconstruction list into a cycle.

Header removal follows the cycle repeatedly. Eventually a buffer becomes
shorter than the five-byte FRAGN header, its unsigned length subtraction wraps,
and `memmove` writes across SRAM. The resulting corruption can overwrite kernel
objects and saved control state. Both benchmark variants contain the same
source defect; their ravens use each ELF's own equivalent instruction.
