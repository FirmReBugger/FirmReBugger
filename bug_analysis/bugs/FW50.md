# Bug Description

CVE-2021-3320 is a frame-type confusion in Zephyr's IEEE 802.15.4 receive
logic. Beacon and MAC-command frames have dedicated exits, but an ACK received
outside scanning mode is not rejected and falls through to code that assumes a
data frame.

The data-frame path derives a header length from fields that an ACK does not
contain. Pulling that value from the packet buffer wraps the data-pointer
adjustment and sets the buffer's data pointer to NULL. Fragment reassembly later
reads through that pointer, causing a denial of service. A radio peer can supply
the ACK over the benchmark's AT86RF233 IEEE 802.15.4 transceiver, so the trigger
is supported by the target hardware.
