# Bug Description

The PWM nanoseconds handler, `cmd_nsec`, resolves its user-selected device with the generic `device_get_binding` API. A successful lookup proves only that the name exists; it does not establish that the object implements PWM operations.

The wrapper then loads the function pointer at the PWM cycles-per-second API offset and calls it unconditionally. Selecting a device from another subsystem substitutes that subsystem's function at the same offset and invokes it with PWM calling conventions, creating type confusion and potentially invalid control flow.

The handler must reject bindings whose API table is not the PWM driver API before performing time conversion or dispatch.
