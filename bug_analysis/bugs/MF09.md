# Bug Description

`can_stm32_attach` calculates a hardware filter-bank index and later uses that index to select bank-specific CAN filter registers. Without a bound, an excessive index could direct register writes outside the configured filter-bank range.

# False Positive Reason

The function compares the calculated index with four before any indexed register access. Values greater than four take the error return, while only indices zero through four reach the bank writes. The out-of-range state is therefore eliminated by explicit control flow before the potentially unsafe operation.
