# Bug Description

`set_code` reads a replacement access code from the serial interface into a
16-byte local stack buffer. Its index is incremented for every non-newline byte
without a capacity check, and the newline path also stores a terminator at the
current unchecked index.

Once the input exceeds the buffer, these stores overwrite the function's saved
registers and return address. The epilogue subsequently consumes the corrupted
return address and redirects control flow into unrelated code. This is a
CPU-side bounds error reachable with an ordinary overlong serial command; no
special MAX32600 peripheral behavior is required.
