# Bug Description

The PWM microseconds shell handler, `cmd_usec`, accepts a device name supplied by the user and resolves it through Zephyr's subsystem-neutral `device_get_binding`. The lookup can return any registered device, not only a PWM controller.

The inline PWM conversion path treats the returned object's API table as a PWM API, loads the function at the cycles-per-second slot, and calls it without checking the device class. For the intended STM32 PWM object this is `pwm_stm32_get_cycles_per_sec`; for a GPIO, UART, or other object the same table offset can contain an unrelated function with incompatible arguments.

The command must verify that the binding exposes the expected PWM API before computing cycles or making the indirect call.
