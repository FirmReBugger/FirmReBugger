# Bug Description

The Modbus function-16 handler accepts as many as 126 registers and reads two
payload bytes per register beginning at receive-buffer offset 7. It does not
verify that the derived source range remains within the 256-byte DMA buffer or
the received frame length. A count of 125 reaches offset 256, and a count of 126
reads through offset 258.

The out-of-bounds bytes are copied into the Modbus register array and can later
be returned by a read-register request, exposing adjacent RAM as well as risking
invalid reads.
