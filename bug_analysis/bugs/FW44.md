# Bug Description

Shell UART transport initialization registers the callback and enables RX
interrupts before the shell thread enables its log backend. In immediate-log
mode, `shell_log_backend_enable` first activates the backend and only afterward
sets the log-output context. A UART RX interrupt can preempt this interval.

If the ISR reports a full RX ring buffer in that interval, synchronous logging
reaches `shell_log_backend_output_func` with a null output context. `shell_write`
then dereferences the null shell pointer and eventually transfers control to
address zero. Set the output context before exposing the backend as active, or
mask RX interrupts across the activation sequence.
