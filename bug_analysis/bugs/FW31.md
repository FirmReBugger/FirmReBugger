# Bug Description

`gsm_get_imei` searches the modem reply for the expected `AT+GSN` echo with
`strstr`. It immediately adds the echo length to the returned pointer and calls
`strtok`, without first checking whether the search succeeded. If the reply is
empty, truncated, or otherwise lacks that echo, the null result becomes a small
non-null address and the tokenizer dereferences unmapped memory.

The function must reject a null search result before performing pointer
arithmetic or tokenization.
