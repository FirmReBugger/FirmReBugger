# Bug Description

The CAN configuration command is registered with enough mandatory tokens to accept an optional mode flag as its final token. An input such as `canbus config DEVICE -s` therefore passes the shell framework's initial argument-count validation.

`read_config_options` consumes `-s` and increments the argument cursor. When control returns, `cmd_config` calls `read_bitrate` without checking whether another argument remains. The bitrate parser loads `argv[pos]`, which is now the shell's NULL `argv[argc]` terminator, and passes it to `strtol`.

The handler must revalidate the cursor after consuming options and reject the command unless a bitrate string remains.
