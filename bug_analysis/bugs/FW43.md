# Bug Description

CAN socket setup calls `z_impl_can_attach_msgq` to attach a message queue to the selected CAN controller. The wrapper loads the `attach_msgq` operation from the device's CAN API table and calls it without checking whether the driver implements that optional operation.

For the STM32 CAN device in this firmware, the `attach_msgq` slot is NULL. The wrapper therefore obtains a zero function pointer and performs an indirect branch through address zero during otherwise valid socket setup.

Optional driver operations must be tested before dispatch. The wrapper should return `-ENOTSUP` when `attach_msgq` is absent while preserving normal behavior for CAN drivers that implement it.
