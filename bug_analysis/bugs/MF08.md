# Bug Description

`cmd_detach` converts the filter identifier in `argv[2]` with `strtol`. If the handler could be invoked with only the command and device name, `argv[2]` would be the shell's NULL terminator and the numeric parser would dereference it as a string.

# False Positive Reason

The command is registered with `SHELL_CMD_ARG` so that the command name, device name, and filter identifier are all mandatory. The shell dispatcher validates that minimum before calling `cmd_detach`; a shorter command is rejected by the framework. Every handler invocation therefore has a populated `argv[2]`, making the suspected NULL conversion unreachable.
