# Bug Description

After locating the expected modem echo, `gsm_get_imei` tokenizes the remainder
of the reply and uses the returned token as the source of `strlcpy`. It does not
check for a null token. A syntactically recognizable response that contains the
echo but no IMEI body therefore sends a null source pointer into the copy
routine, which faults on its first source read.

The parser must validate that a nonempty IMEI token was returned before copying
it into the destination buffer.
