# Bug Description

In `gnrc_rpl_srh_process`, the RPL source-routing header controls the current
address position and compression lengths used to derive an element of the
header's address vector. The function does not first prove that the resulting
element lies inside the supplied header. A malformed position can therefore
wrap the address calculation and make `current_address` point outside the
vector.

The function copies bytes from that invalid address into a temporary IPv6
address and later copies the processed value back through the same invalid
pointer. This out-of-bounds access can overwrite packet-buffer contents or
allocator metadata, causing denial of service and potentially enabling a more
controlled memory corruption. This defect is
[CVE-2023-24817](https://github.com/RIOT-OS/RIOT/security/advisories/GHSA-xjgw-7638-29g5).
