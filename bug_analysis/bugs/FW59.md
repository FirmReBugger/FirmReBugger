# Bug Description

This is [CVE-2020-12141](https://nvd.nist.gov/vuln/detail/CVE-2020-12141).
Contiki-NG's `snmp_ber_decode_string_len_buffer` decodes a BER string's length
but does not verify that the input contains all long-form length octets or that
the resulting content length is no greater than the bytes left afterward.

One crafted request can claim more long-form length octets than remain, making
the decoder read beyond the packet while building the length and decrement its
remaining-byte count through zero. Another can provide the length octets but
declare content larger than the post-header input. In both cases unsigned
arithmetic wraps the remaining count, the decoder advances its cursor beyond
the packet, and subsequent SNMP parsing dereferences that out-of-range cursor.

A correct fix first verifies that the complete BER length header is present,
then rejects any decoded content length greater than the remaining input before
changing either the count or cursor. Short-form and long-form BER lengths whose
header and content both fit are valid and must not be reported.

The firmware identifies the CC2538DK with a SmartRF06 board and CC2538
evaluation module. TI's [CC2538EM reference design](https://www.ti.com/tool/CC2538EM-RD)
and [CC2538SF53 part record](https://www.ti.com/product/CC2538/part-details/CC2538SF53RTQT)
establish a 56-pin CC2538 device with 512 KiB flash, 32 KiB RAM, and an IEEE
802.15.4 radio.

The [CC2538 User's Guide, rev. C](https://www.ti.com/lit/ug/swru319c/swru319c.pdf)
documents ordinary radio-frame reception and the 128-byte receive FIFO in
sections 23.4, 23.7, and 23.10. The defect occurs after received bytes have
entered the software SNMP parser and depends only on attacker-controlled BER
data and ordinary Cortex-M3 arithmetic and loads; no synthetic interrupt order
or impossible peripheral value is load-bearing. TI's
[CC2538 errata, rev. A](https://www.ti.com/lit/er/swrz045a/swrz045a.pdf)
lists reset/debug, timer, clock-divider, and USB issues, none of which changes
this software parsing chain.
