# Bug Description

RIOT's newlib initialization is not protected against interrupt-context stdio.
The initializer marks the reentrancy structure initialized before replacing and
fully configuring its standard-stream objects. An interrupt that performs
formatted output in that interval observes the completed flag and skips
initialization. Depending on the exact interruption point, it can pass a
read-only fake stream into the normal setup path or consume a newly published
stdout whose callback table has not yet been installed. The former causes a
write through the read-only fake object; the latter causes the flush path to
call a null write callback.

The missing invariant is atomic publication of the initialized flag and all
standard-stream pointers. Protecting initialization against interrupt reentry,
or publishing the flag only after every stream is usable, prevents the race.
